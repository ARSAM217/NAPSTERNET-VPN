# NAPSTERNET-VPN

یک نصب‌کننده‌ی ساده برای راه‌اندازی **Xray / VLESS + REALITY** روی یک VPS لینوکسی که استفاده از VPN/Proxy را صراحتاً مجاز می‌داند. خروجی نصب، لینک `vless://` و در صورت نصب بودن `qrencode`، QR قابل اسکن است.

> **مهم**
> - این پروژه برای VPS مستقل با Ubuntu 22.04 یا 24.04 و دسترسی `root` طراحی شده است؛ GitHub فقط محل نگهداری کد است و خودش سرور VPN نیست.
> - طبق شرایط منتشرشده‌ی Runflare، اجرای VPN، پراکسی و تونلینگ روی زیرساخت آن‌ها ممنوع است. این پروژه را روی Runflare اجرا نکنید.
> - این اسکریپت تنظیمات فایروال را تغییر می‌دهد و پورت TCP/443 را باز می‌کند. قبل از اجرا مطمئن شوید SSH روی پورت دیگری نیست یا دسترسی SSH شما قطع نمی‌شود.
> - سازگاری VLESS + REALITY را در نسخه‌ی فعلی NPV Tunnel / NapsternetV خود بررسی کنید. اگر گزینه‌ی REALITY در کلاینت شما پشتیبانی نشود، لینک وارد می‌شود ولی متصل نخواهد شد.
> - استفاده از سرور و رعایت قوانین محل استفاده و مقررات ارائه‌دهنده بر عهده‌ی مدیر سرور است.

## پیش‌نیازها

- VPS با Ubuntu 22.04 یا 24.04، معماری `amd64` یا `arm64`
- دسترسی SSH و `root` یا کاربر دارای sudo
- IP عمومی ثابت
- اجازه‌ی ارائه‌دهنده برای میزبانی VPN/Proxy
- پورت ورودی TCP/443 باز باشد

## نصب

مخزن را روی VPS کلون کنید:

```bash
sudo apt-get update
sudo apt-get install -y git
git clone https://github.com/ARSAM217/NAPSTERNET-VPN.git
cd NAPSTERNET-VPN
sudo bash scripts/install.sh
```

اسکریپت Xray را از مخزن رسمی XTLS/Xray-install نصب می‌کند، UUID و کلیدهای REALITY را می‌سازد، سرویس systemd را فعال می‌کند و لینک اتصال را چاپ می‌کند.

## خروجی و اتصال

در پایان نصب، لینک `vless://...` چاپ می‌شود. آن را کپی کنید و در NapsternetV از گزینه‌ی Import/Paste link وارد کنید. QR نیز اگر `qrencode` نصب شده باشد در ترمینال نمایش داده می‌شود.

## مدیریت

```bash
sudo systemctl status xray
sudo systemctl restart xray
sudo systemctl stop xray
sudo journalctl -u xray -n 100 --no-pager
```

برای دیدن لینک فعلی (فایل حاوی اطلاعات اتصال محرمانه است):

```bash
sudo cat /root/napsternet-vpn-client.txt
```

**این فایل را در GitHub، گروه یا فضای عمومی منتشر نکنید.**

## حذف

```bash
sudo bash scripts/uninstall.sh
```

حذف، Xray و فایل‌های تنظیمات این پروژه را پاک می‌کند. قبل از حذف، از فایل‌های موردنیاز نسخه‌ی پشتیبان بگیرید.

## امنیت

- پورت پنل مدیریتی یا API عمومی ایجاد نمی‌شود.
- کلید خصوصی REALITY فقط روی سرور ذخیره می‌شود.
- لینک کلاینت مانند رمز عبور عمل می‌کند؛ آن را خصوصی نگه دارید.
- برای هر کاربر، بهتر است UUID جداگانه بسازید و در صورت افشا، همان کاربر را حذف/تعویض کنید.
